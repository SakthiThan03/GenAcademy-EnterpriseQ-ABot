# 2–3 minute demo recording script

1. Show the repository structure and six fictional policies (20 seconds).
2. In a terminal, run `streamlit run app.py` and open the local app (20 seconds).
3. Ask: “How many PTO days do full-time employees receive?” Show the answer and its Employee Handbook citation (25 seconds).
4. Ask: “What must a new remote employee do for secure access?” Discuss possible cross-document retrieval limitations (35 seconds).
5. Ask: “What is the company stock ticker symbol?” Show abstention (20 seconds).
6. Run `python evaluate.py`; open `evaluation_results.csv` and summarize retrieval precision, recall, and failures (40 seconds).
7. Close by explaining that this is an extractive TF-IDF baseline and how you would upgrade to dense embedding + reranker + LLM (20 seconds).

Record with macOS Screenshot toolbar (Shift-Command-5) or QuickTime Player. Upload the recording alongside the zip and report.
